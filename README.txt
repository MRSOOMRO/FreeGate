FreeGate Android source project

Open in Android Studio and build the app with Gradle. Requires Android 8 or newer.
Install OpenVPN Connect on the phone. In FreeGate, refresh the server list,
choose a server, tap Save OpenVPN profile, and save the .ovpn file. In OpenVPN
Connect, import the saved file and connect. If asked, username and password
are both vpn.

VPN Gate CSV: https://www.vpngate.net/api/iphone/
Servers are volunteer-run and may disappear without notice. This app only
lists servers and exports OpenVPN profiles. The tunnel runs in OpenVPN Connect.
Do not use volunteer servers for sensitive work. This source is provided as-is.
